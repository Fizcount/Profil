# Profil Desa Ciledug Wetan

Static website untuk GitHub Pages.

## Struktur
- `index.html` — homepage
- `css/style.css` — styling responsive
- `js/script.js` — mobile menu & active navigation
- `assets/images/` — tempat foto desa

## Cara pakai
1. Ganti placeholder foto pada CSS/HTML dengan foto asli.
2. Perbarui kontak resmi dan titik Google Maps setelah diverifikasi.
3. Saat URL website Aduan Sampah sudah tersedia, ubah card "Segera Hadir" menjadi tombol link.
4. Push folder ini ke repository GitHub.
5. Aktifkan GitHub Pages dari Settings → Pages → Deploy from a branch.
